Reproduce the nested call measurements

Terminal
mkdir -p build
ZEROPAGE_EMU_FILTER=optimization_reference/abi_calls/ zig build emu-test > build/abi-calls.log 2>&1
awk '/^host-(stack-)?metrics/ && $2 ~ /nested_(static|stack)/' build/abi-calls.log

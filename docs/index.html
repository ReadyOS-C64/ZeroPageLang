Philosophy

Use familiar types, functions, and control flow while keeping the costs of the 6510 visible. The language uses Zig's parser for ordinary syntax. ZeroPage lowers a documented subset and adds declarations for C64 concerns such as banking, zero-page ownership, and module loading.

A small program needs only a main and the helpers it calls. A larger program can choose where code and data live, and inspect the assembled memory map to check those choices. Language reference · Runtime

C64 features

Hardware and I/O

Write to the VIC-II border register, draw directly into screen RAM, or use the PETSCII console, keyboard, KERNAL, and timing helpers. Volatile pointers expose memory-mapped devices. Inline asm { ... } embeds 6502/6510 instructions in the same source. Library API · Inline assembler

Memory and banking

Name C64 and REU ranges in a memory block. Reserve them for arenas, fixed-block pools, the software stack, or DLL windows. Set the PRG load and entry addresses independently. Place selected code and constant data at fixed addresses or copy them into RAM under ROM at startup. Memory model

Zero page and call frames

Specify which zero-page bytes the compiler may use and which are reserved by your code or the system. Static frames give functions fixed storage. callconv(.stack) enables checked recursive frames in a configured RAM region. Calling conventions · Zero-page policy

REU and DLLs

Use explicit DMA transfers and typed views to store data in an REU. A DLL can load from disk into an REU cache, then relocate into a C64 RAM window for execution. DLLs can share a window, and configured state ranges can survive a swap. Typed imports and dependency policies make those calls visible in source. REU and DLLs

Build artifacts and tests

The compiler emits only the runtime helpers it uses. Inspect the 64tass assembly, VICE labels, and memory map. Use the Peddle 6510 test runner for target assertions and VICE for emulator integration. CLI reference · Testing

The Zig subset

Values and storage

bool, u8, i8, u16, i16, 16-bit usize, supported near and volatile pointers, fixed arrays and structs, enum(u8), scalar and pointer optionals, and narrow tagged unions.

Control flow and composition

Typed functions, local @import, if, while, fixed-array and zero-based range for, scalar switch, and layout queries such as @sizeOf.

Target semantics

Runtime array indexing is unchecked. Arithmetic retains the low bits of the destination width. Strings have PETSCII helpers and fixed-capacity buffers.

Unsupported forms

std, generics, general comptime, slices, floating point, division, error unions, try, and defer produce diagnostics. Full language reference

Frames, recursion, and interop

Follow data across static and stack calls, and understand the ReadyOS boundary.

Static frames and return registers

Static calls copy arguments into fixed storage owned by the callee. The frame has program lifetime and is not reentrant. Record arguments copy flattened fields. Byte returns use A. Words and near pointers return low byte in A and high byte in X. Static aggregate results use return storage. Inspect the generated labels to follow the argument cells.

26_static_abi_metadata.zp64
const c64 = @import("c64");

memory {
    region call_stack: c64 at 0xc800 size 0x0400;

    stack in call_stack;
}

fn helper(a: u8, b: u8) callconv(.static) u8 {
    return a + b;
}

export fn main() callconv(.static) void {
    c64.console.clear();
    c64.console.print("ABI METADATA\n", .{});

    var total: u8 = helper(2, 4);
    if (total == 6) {
        c64.console.print("STATIC OK\n", .{});
        c64.vic.border = 5;
    } else {
        c64.console.print("STATIC BAD\n", .{});
        c64.vic.border = 2;
    }
}

A separate stack for recursion

Ordinary functions use fixed frame storage. For recursion, reserve RAM for the software stack and mark the recursive function with callconv(.stack). This example counts down to zero and returns the green border value. An exhausted software stack traps.

32_stack_recursive_border.zp64
const c64 = @import("c64");

memory {
    region call_stack: c64 at 0xc800 size 0x0400;

    stack in call_stack;
}

fn borderFrom(value: u8) callconv(.stack) u8 {
    if (value == 0) {
        return 5;
    }
    return borderFrom(value - 1);
}

export fn main() callconv(.stack) void {
    var border: u8 = borderFrom(4);
    c64.vic.border = border;
}

Compile the file and inspect the generated assembly for the entry and frame setup. The software stack holds the supported call-frame values. The 6510 hardware stack still holds CPU return addresses. Frame layouts and ABI limits

Configure a stack region in visible RAM. Its software stack and frame pointers use zero-page pairs. The 6510 hardware stack still holds the machine return address and compiler wrapper saves. The stack convention supports the documented scalar/pointer subset and checks frame bounds. Stack overflow traps. Avoid assuming every static-frame feature is available in a stack frame.

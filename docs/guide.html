The ZeroPage programming guide

A guide to writing ZeroPage programs, from typed values and C64 hardware to a complete game and relocatable DLLs.

How to follow the guide

Start with types and control flow if you are learning the language. Follow screen and keyboard I/O into the Tic-Tac-Toe case study to see those choices in an application. For memory-intensive projects, read memory placement before arenas and REU views. The DLL walkthrough starts with one call and works up to a shared execution window.

Code labelled as an excerpt shows part of a program. Complete source links let you read the surrounding declarations and run the example. Build and run links open commands on a separate page. The setup page collects tool installation.

Find a worked example by task

  • Carry a byte counter into a word and predict its displayed bytes.
  • Choose a snapshot or an in-place update for game state.
  • Pass a string address and length to assembly and trace what the wrapper preserves.
  • Capture a KERNAL register result in a typed function.
  • Pass a filename to KERNAL and capture carry before the assembly wrapper restores status.
  • Reserve bytes for application code and read the resulting zero-page map.
  • Encode a record in a near arena or edit a range of far records and flush it to the REU.
  • Reuse one working buffer to update an entire far table.
  • Calculate a map's REU and scratch capacity and test both bounds.
  • Stage tile data in REU and fetch a fixed subrange directly to the screen.
  • Keep mutable tile state separate from artwork so the two follow different transfer paths.
  • Call the same disk DLL two ways, then trace an address into the execution window.
  • Keep a byte across DLL unload and reload.
  • Compare preload, on-demand, and explicit loading for the same exports.
  • Package one DLL build for two applications with different loading policies.
  • Build a disk-backed score updater and diagnose a bad memory plan, signature, or disk.
  • Exercise a stack limit with a passing program and a one-byte-smaller variant.
  • Trace a word argument through a nested call.
  • Trace a three-byte record through a static call.
  • Measure a zero-page policy with the same source workload and assertions.
